## 三、钢化玻璃设备使用与维护（重点操作规程）

### 3.1 通用安全与警告（务必遵守）

- 加热炉炉体上部重量在 3 吨以上，炉膛内表面为高铝板保温材料，上部炉体升起空间有限。
- **只有加热炉冷却至常温后方可打开炉膛**；炉顶升起后必须在立柱上插安全销并锁死，并使上部炉体下降到轻压安全销位置。
- 人员进炉前**必须切断炉体部分全部电源**，佩戴手套、安全帽、防护眼镜、工作服等。
- 严禁在无安全保障的情况下进入上下风栅之间作业；勿随意按压启动/旋钮开关、踩踏出入段脚踏开关；上下玻璃时穿劳保鞋、戴劳保手套防划伤烫伤。

### 3.2 加热炉维护

**（1）陶瓷辊道清洁**
- 判断依据：钢化玻璃表面出现辊道遗留的可见痕迹时，停炉降温、升起炉顶后清洁。
- 清洁程序：刮刀轻刮可见污斑 → 400~600 号细刚玉砂纸均匀打磨低速旋转的辊道 → 吸尘器除尘 → 干净软布浸**丙酮或四氯化碳**等挥发性液体反复擦拭至无污迹（**切勿用水或其它清洁剂**）→ 洗净的手触摸检查；不洁则重复以上程序。
- 操作便利法：将厚木板横担在下炉体上，人员横躺木板上操作；炉顶升起后必须插上安全销方可进入炉内。

**（2）陶瓷辊道更换**
- 警告：**必须待加热炉冷却后**方可更换，否则金属轴头可能因热脱胶而松动。
- 至少 3 人操作（两侧各 1 人、中间 1~2 人）；拆卸顺序：先拆皮带轮 → 松开并去掉轴限位固定螺钉 → 拆下轴承 → 在拉出端架板孔内垫密实纸板 → 多人同时托辊缓慢外拉（严禁碰撞、划伤）。
- 安装：先在架板安装内孔装好，再装两端轴承与一端皮带轮，手动检查转动灵活平稳。

**（3）炉体升降传动装置**
- 立柱内梯形螺杆：炉顶每升降一次后（或每月至少一次）喷适量 N46 润滑油。
- 锥齿轮传动：每季度涂一次锂基润滑油。
- 炉顶提升链条：每月一次 N46 机油；使用约 6 个月后调整张紧链轮适当张紧。
- 炉顶升降减速机：油位保持油窗中间位置，每年更换一次（建议 N46）。

**（4）主传动**
- 摆线针轮减速机油位保持油窗中间，每年更换一次（建议 N46）。
- 链条张紧：通过调紧弹簧座微调；无效时松开主传动电机与底座连接螺钉，旋转限位螺钉推动电机至合适位置后上紧。
- 主传动链条润滑：每周一次 N46 润滑油。

**（5）陶瓷辊道传动装置**
- 圆形皮带传动：辊道卡滞时皮带打滑可起保护作用；经常观察传动是否正常，异常及时处理。
- 皮带张紧力调整：松轴承座固定螺栓 → 顶紧上部调整螺栓 → 固定；张紧力宜"**保证辊道正常传动所需的最小张紧力**"——过小打滑、过大恶化辊道与传动轴受力甚至损坏辊道与皮带。

**（6）轴承润滑**
- 润滑部位：主传动轴轴承、陶瓷辊道轴承（每半年）、炉门轴轴承、炉顶升降传动轴轴承、炉顶升降梯形螺杆轴承（锂基润滑脂）等。
- 周期：陶瓷辊道轴承与炉门相关项约半年一次，其余约一年一次。
- 辊道轴承注脂量以略有富余、能维持润滑的最小剂量为佳（此时轴承工作温度最佳）。

**（7）更换热电偶**
- 热电偶损坏或断裂应及时更换；须炉子完全冷却后升起炉顶操作。
- 步骤：分离两根导线并标明位置 → 端部从插入孔拉出伸直并拉出炉体 → 薄机油润滑新热电偶表面、插入管内喷洒润滑油 → 校直后小心插入护套管（握元件基部防死弯）→ 端部露出后拉到位、轻弯端部插入被测元件插入孔 → 连接上部导线。

**（8）更换加热元件**（须 3 人协作，勿伤陶瓷辊道）
- 管状炉丝：断开配电柜 KG2/KG3 电源 → 拆端部电源线 → 向里推动端部并逆时针旋转 30° 卸下 → 拆弹簧、陶瓷钢套 → 整体抽出；新件平直抬起、轻缓插入辐射管 → 套瓷头、钢套、弹簧 → 压盖内缘凸起对准卡环槽口推进，顺时针旋转 30° 固定 → 接电源线并检查防短路。
- U 型炉丝：断开电源 → 升起上炉体 → 上推上部辐射板脱离四角固定销、拔出热电偶 → 斜向取下辐射板 → 更换炉丝（穿瓷管瓷片）→ 装回复位 → 接电检查。
- 警告：安装炉丝须使其处于自然状态，不能翘曲或扭动。

### 3.3 入片段

- 入片段状态直接影响钢化质量，弯钢化时玻璃各边平行、垂直与曲率取决于进炉位置和状态。
- 传动链条定期检查、及时张紧并加机油，**可逆式上、下片段链条**尤甚（不及时张紧影响传动进度）。
- 减速机定期检查油标油位，油位到下限及时加注至上限；每半年更换润滑油（N46；-10~0 ℃ 环境可用 N32）。
- 上下片台气路定期检查漏气、卡滞并及时排除。
- 定时检查光眼位置与感应距离（防玻璃跑偏或外因碰撞光眼支架）；每半年检查胶辊平面度（误差 ≤0.5 mm）及老化情况，大块脱落影响平稳运行时更换。

### 3.4 平风栅的使用与维护

- **吹风距离（风栅距离）**：上下风嘴顶部母线与所加工玻璃上下表面之间的相对距离；不同厚度玻璃对应距离不同（见工艺参数表），表中数值仅供参考，应按实际钢化效果调整。

**（1）风栅上、下限调整**
- 脱开与开合电机传动轴链轮挂接的 2 套传动链条（08B 单排）→ 人工将上下风栅平行盘至最小闭合点与最大张开点 → 确定上、下限保险开关位置（以后一般不需再调）。

**（2）风栅距离调整方法**
- 另设上、下限接近开关作为正常工作限位；先按上一步确定上限工作位；下限工作位即风栅距离。
- 按玻璃厚度选择下限工作位 → 按顶下降按钮使风栅闭合 → 在上下风栅前后均匀确定 4 个测量点（取风栅链条升降吊挂点上下部位对应铝风嘴）→ 若闭合工作位过大/过小，调整下限接近开关位置 → 微调吊挂杆与吊挂链条（12A）连接的调节套，使各测量点风栅距离达到所需距离，即调节完毕。

**（3）辊道传动链条张紧**
- 06B 双排链，定期检查松紧；张紧可消除噪音、减少辊道振动，但**不宜过紧**（影响链条寿命）。
- 判断标准：拇指按压链条有弹性、但几乎没有下压量为合适。
- 通过调整传动端张紧链轮位置实现。

**（4）方纶绳的更换**
- 玻璃碎片易损坏辊道方纶绳，发现断裂应立即维修或更换。
- 更换要点：清除辊道表面胶性物质及粘接物保证光洁 → 缠绕时始终拉紧、平直不扭曲、螺旋螺距均匀，**旋向与相邻辊道相反** → 内侧涂胶与辊道粘接、未绕绳表面无胶（防碎片粘附）→ 头部固定牢固，固定螺钉头不得高出辊道表面。
- 可拆辊道更换，也可不拆直接缠绕——直接缠绕须将上风栅升至最高并用方木等垫起后操作。

**（5）辊道拆卸**
- 适用：辊道轴承损坏或辊道损坏。
- 顺序：拆除辊道端部传动链轮 → 拆传动端（装链轮端）轴承定位卡簧 → 从被动端向传动端垫铜棒或木棒敲击（防损坏轴头/轴承），直至辊道从轴承座中穿过；部分轴承取下压盖即可拆下辊道。

**（6）润滑部位**
- 辊道传动减速机及风栅开合减速机油位保持油窗中间（N46），每半个月检查一次。
- 辊道轴承及各提升轴轴承：锂基润滑脂，每半年一次。
- 传动链条：N46 润滑油，每月喷注一次。
- 其它轴承及滑动部位：每年检查并润滑一次。

### 3.5 设备一般保养维护

- 放片段、取片段、平/弯钢化段、炉体主传动、炉顶提升等所有传动链条：定期检查工况、张紧及机油润滑。
- 所有减速机加注 N46 齿轮油，油位到下限及时补至上限；每半年全部更换一次。
- 空压机按标准维护保养；储气罐、空气过滤器一般**每天排水一次**（南方潮湿地区缩短间隔）；三联体过滤器定期排水、油雾杯保持油位。
- 风机执行机构及炉顶平衡气路**不允许采用油雾润滑**；随时观察气路，漏气及时处理；风机按《风机使用说明书》维保。
- 坚持工作日巡查制度，按维护保养计划进行日检/周检/月检/季检/年检，及时消除故障隐患。

## 四、钢化工艺技术要点

### 4.1 玻璃特性与钢化原理

- 钢化玻璃：通过物理或其它方法使普通玻璃表面产生**压应力层**而获增强的玻璃。
- 特性：机械强度为普通玻璃的 **4~5 倍**；可经受 **250~320 ℃** 的温度突变；破碎后呈钝角小颗粒状、不易伤人（安全性）；但存在**"自爆"**特性。
- 钢化工艺基本要求：
  1. 快速均匀加热到钢化温度，玻璃各部分、表面与中央温差极小，上下表面对称加热；
  2. 加热后以最佳冷却速度尽可能均匀冷却（冷却速度取决于厚度等性能），上下表面冷却均匀；
  3. 钢化过程中玻璃不停运动，传送不得产生变形、辊道映射及其它痕迹；
  4. 加热后玻璃须尽可能快地开始冷却。

### 4.2 加热与温度均匀性

- 加热温度均匀是行业长期最难解决的问题；炉膛加热均匀是温度均匀的基本条件。
- 影响均匀加热的因素：炉膛均匀性；降低炉温时应按玻璃厚度相应增加加热时间；均匀放片与固定放片位置是均匀加热的有效手段；操作工选择的加热参数及炉子负载状况；加热时间变化的影响。
- 温度与时间设定规律：**薄玻璃高温短时，厚玻璃低温长时**（详见 4.10 参数表）。
- 出炉温度的权衡：出炉温度高 → 成品率高但光学性能稍差；出炉温度低 → 光学性能好但成品率低。一般成品率控制在 **95% 左右**为最佳温度选择，操作工应依据成品质量与破碎率不断调整加热时间，找到光学性能与成品率的最佳结合点。

### 4.3 冷却

- 空气是理想冷却介质：冷却中玻璃保持清洁；改变风压即可精确得到冷却速度；玻璃各部位冷却效果一致；风机简单可靠。
- 冷却分两个阶段：
  - **急冷（风压+时间）**：玻璃钢化所必需，决定钢化程度；
  - **冷却（风压+时间）**：仅使玻璃降温便于卸片，与钢化程度无关。
- 关键控制点：风压大小是碎片大小的决定因素；风栅距离作用等效于风压，也是钢化程度的重要因素；**上下吹风对称性是平整度的决定因素**；**上下风压差是调整平整度的关键因素**。
- 规律：薄玻璃要求风压高、时间短；厚玻璃风压低、时间长。

### 4.4 炉膛温度均匀的操作要领（放片）

- 注意炉内纵向与横向负载均匀：每炉放片位置均匀、各炉间隙时间均匀。玻璃沿炉子纵向往复运动时，**玻璃边缘邻近辊子区域及两块玻璃之间的辊子易过热**。
- 产品规格大小长短不一时：纵向玻璃板间空隙会导致辊子温度不匀，放片应尽量合理、下一炉补上空隙；空隙一般 ≤ L/2（L 为板长），大于 L/2 的空隙不放玻璃；**玻璃纵向摆放，避免横向放片**，横放玻璃在过热点易碎。
- 同规格大批量生产：可采用固定摆放位置，获得最佳钢化效果与成品率。
- 使用单独加热元件时玻璃摆放与其对应（加热元件温度最高点在中间，玻璃放放片台中间），可通过改变摆放调节炉温分布。

### 4.5 常见缺陷及原因分析（操作口诀）

| 现象 | 主要原因 / 对策 |
|---|---|
| 出炉后在风栅急冷时破碎 | 加热温度过低或加热时间太短，未达钢化所需温度/时间 |
| 在冷却段突然暴碎 | 风压过高；或原片有缺陷（钻孔过多、孔边缺陷等） |
| 冷却结束后表面出现波浪 | 炉膛温度过高、加热时间过长；或原片本身有波筋 |
| 表面麻点（星星点状） | 新炉初始阶段正常现象；陶瓷辊表面积物；进炉玻璃下表面不干净 |
| 表面麻点（密集桔皮状） | 玻璃离开加热炉时表面温度太高；钢化厚玻璃时陶瓷辊表面温度过高 |
| 玻璃中央白雾状/光学变化（每批生产前几炉） | 陶瓷辊表面温度过高、进炉间隙时间长、下部设定过高、热平衡吹风压力太低、长期未用 SO₂。机理：辊子释放热量大于加热元件作用，玻璃边缘先向上弯曲，辊子中间部位表面压力过大 |
| 前后两端向上翘曲 | 玻璃上部温度高于下部，冷却段上部冷却慢 → 适当提高下部温度，或降低上风栅与玻璃距离，或降低下部吹风压力（一般调上下风栅距离与上下风压解决） |
| 玻璃中间向上凸起 | 玻璃下部温度高于上部，冷却段下部冷却快 → 降低下部温度或提高上部温度；同时可提高冷却段下部风压、降低上部风压，拉大上风栅或减小下风栅与玻璃距离 |

### 4.6 厚玻璃（12~19 mm）钢化的特殊方法

厚玻璃指 12~19 mm，为避免/减少进加热段后因热振动炸炉（俗称"炸炉"），需特殊技术：
1. 设定温度取下限为佳，并适当延长加热时间；
2. 玻璃进炉前关掉下部加热开关，进炉约 2~3 分钟后再打开；
3. 进炉速度和加热往复速度尽可能慢（以伺服不过流为前提），减少往复次数以降低炸炉几率；
4. 刚生产完薄玻璃需立即转产厚玻璃时，先打开炉顶锥形阀和前炉门，让炉膛降温至适合厚玻璃的温度方能进炉。

### 4.7 特殊形状与特殊原料玻璃钢化

> 任何特殊玻璃正式生产前都应先做小批量试验，确定实际生产设定值。

| 玻璃类型 | 工艺要点 |
|---|---|
| 带孔、开槽玻璃 | 按 Refine glass 公司标准钻孔、切口、开槽；加热时间比同种质量玻璃**增加 2.5%~5%** |
| 带尖角玻璃（角 < 30°） | 加热时间比同质方形玻璃**增加约 2.5%** |
| 压花玻璃 | 避免较长加热时间造成波纹，不平平面可朝辊子放置；加热时间按最厚处厚度定；原料不单一再增 5~10%；风压按最薄处厚度定；增加加热时间以满足碎片颗粒数要求 |
| 吸热玻璃（有色） | 加热时间比同厚度一般玻璃**减少约 5%~10%** |
| 镀膜玻璃、热反射玻璃 | 膜面朝上；上部加热温度视需要提高 5~10 ℃；加热时间比同颜色同厚度普通玻璃**增加 2.5%~10%**；**不使用 SO₂** |
| 釉面玻璃 | 釉面必须干透；底部温度适当增加；可能弯曲可用调节风压校正；热平衡压力**降低 50%**；加热时间视釉的颜色而定 |

### 4.8 玻璃钻孔、开槽和切口的标准

1. 孔边至玻璃边的距离应 **> 玻璃厚度的 2 倍**，小于此尺寸时应在该边切口；
2. 孔径最小 5 mm，且应 ≥ 玻璃厚度；
3. 两孔之间必须有 **2 倍玻璃厚度以上**的距离；
4. 开槽或方孔玻璃应在拐角处圆滑过渡，过渡 R ≥ 玻璃厚度；
5. 孔及切边表面要平滑，大孔边应研磨。

### 4.9 几点说明及注意事项

**（1）SO₂ 气体的使用方法**
- 仅在新炉首次生产前、或陶瓷辊清洁后开始生产前半小时使用：开 5~10 分钟，流量 1~4 升/分，压力 0.05 MPa，一般炉外闻到硫磺味即可关闭。
- 加热炉未达到工作温度前不得通入 SO₂。
- SO₂ 应尽量少用：用量过多玻璃会发蓝、辊子表面结褐色点、厚玻璃表面出现点状痕迹、增加清洁次数，并影响加热元件及炉体使用寿命。
- 无 SO₂ 时可用硫磺粉替代。未按设备厂家指导使用 SO₂ 造成炉体损坏的，厂家不承担责任。

**（2）正确理解 GB（国标）碎片要求**
- 国标规定 50 mm × 50 mm 范围内碎片不少于 40 粒，**是以 5 mm 厚度为标准制定的**。
- 碎片不是越小越好：钢化玻璃压应力层是叠加而成的，若 19 mm 玻璃破碎后也要求 40 粒以上，将变成细小粉末，反而影响安全性。
- 正确理解：破碎后的颗粒尺寸**不应小于玻璃厚度**。

**（3）已钢化玻璃禁止二次钢化**
- 钢化玻璃（含热强化玻璃）不能再次进炉钢化——二次加热时极易破碎。
- 任何情况下，破碎玻璃不得留在加热炉内，应及时清理，否则影响加热温度平衡并损坏辊道；由此引起的问题设备厂家概不负责。

## 五、建筑玻璃工艺技术（防火型水平式钢化设备）

以设备技术配置方案为例，要点如下：

- **设备用途**：生产平型钢化玻璃（热增强安全玻璃），产品用于建筑、家电、汽车等行业。
- **产品规格**：
  - 常规玻璃：最大装载 6000 mm × 2600 mm，最小平面 450 mm × 300 mm，厚度 4~19 mm；
  - 防火玻璃：最大 6000 mm × 2400 mm，最小 450 mm × 300 mm，厚度约 5~12 mm；
  - 原片要求：符合 GB 11614—1999，倒角、精磨边、清洗、干燥，无可见气泡与杂质；可加工 Low-E（低辐射）等浮法玻璃，Low-E 玻璃验收单片尺寸受限（如 5~12 mm 低辐射 Low-E 最大约 900 mm × 1500 mm，白玻验收单片面积 ≤ 2 m²）。
- **质量要求**：符合 GB 15763.2—2005《建筑用安全玻璃 第 2 部分：钢化玻璃》，并与日本 JIS R3206、美国 ANSI 97.1、欧共体 EN 13024-1 等标准等效；防火玻璃耐火性能符合 GB 15763.1—2009 非隔热型防火玻璃（C 类）耐火极限 1.00 h 要求（6~19 mm）；常规玻璃成品率 ≥ 98.5%，弓形变形约 ≤ 1.2‰、防火玻璃 ≤ 2.0‰（OCR 数值，供参考）；实际产能约为最大生产能力的 50%~85%。
- **工艺过程**：选择已储存订单参数或重设参数 → 人工放片（整片或多片）→ 自动进入电加热炉往复加热 → 出炉至风栅辊台吹风急冷 → 输送到出片辊台 → 人工卸片。
- **关键结构与配置**（摘要）：
  - 入（出）片辊台：Ø54 mm 精拔无缝管包胶辊道（Ø48 mm 辊芯），入片辊包胶、出片辊缠耐高温石棉绳；圆形胶带正交布置传动，调速 100~600 mm/s，电机 N=4 kW。
  - 电加热炉：石英辊道 63 根（Ø90 mm，间距 120 mm），浮动固定便于装卸；120 个加热控制区（可控硅控制，独立调温）；对流风机 10 套（310S 不锈钢，变频，风冷却延长轴承寿命），对流箱体矩阵排列，加热丝置于加热单元内；炉丝为镍铬炉丝（上部置于对流单元内部）；保温为硅酸铝板毡（250~300 mm）表面刷耐高温胶并采用锚固技术；炉体升降电机驱动（Vmax≈80 mm/min）。
  - 风栅辊台：辊道 71 根（Ø54 mm 全部缠绳，间距 120 mm）；风栅片 70 片×2（上/下）=140 片，铝合金风嘴整体开孔带挡片便于清理；丝杠传动，调速 5~30 mm/min，定位精度 ±1.5 mm；上下风栅单独升降。
  - 供风与电气：高、低压风机 355 kW×2 + 110 kW×1（变频）；风压调节阀 2 件、管路气动通断阀 3 件、静压箱 2 件；PLC（西门子）、变频器/接触器等低压元件西门子，传感器欧姆龙/图尔克；气动元件台湾新洋；设备总装机容量 2031 kW，供电容量 ≥ 1250 kVA。
  - 工作环境：气温 -20~40 ℃，设备周围避免气流干扰；定期维护周期约 3 个月（不含清洁石英辊时间）。

## 六、汽车玻璃工艺技术（玻璃压制生产线）

### 6.1 炉体（玻璃压制炉）外观构成与制造标准

- **上、下片台**：上片台配置玻璃定位功能；上片台（排片接触热玻璃部分）及炉体接近辊道使用陶瓷；上片台具排炉功能；配储物箱、插座电源、灯带；同步带传送提高同步性。
- **炉体**：上下剖开式钢结构，上部炉体通过炉顶提升机构自由升降（升降高度 500 mm）；保温采用高密度陶瓷纤维板，表面刷耐高温胶，炉膛内侧铺设磁化高铝板防止掉渣；对流段与非对流段之间设隔墙防串温；炉体两侧壁温度不高于车间环境温度 30 ℃。
- **炉丝**：北京首钢炉丝，按炉体大小不同排列，结构简单、安装方便、寿命长；悬挂式安装便于维修；各根炉丝独立安装、拆换故障炉丝不损坏其它炉丝；固态继电器控制通断，矩阵分布、循环加热；每根炉丝单独热电偶测温、可单独设定温度与功率，保证炉内温度均匀。
- **辊道与辐射板**：辊道孔采用开模定制保温砖，直径精确、间隙小、耐用保温易更换；底部辐射板采用瓦楞形结构增加强度，高温下不易变形。
- **控制系统**：柜内电器件及配线均用国标；动力电缆（含变频器与风机连接电缆）由甲方提供；现场尽量不做地沟、以线槽走线为主。

### 6.2 控制系统特点

- 工业控制机 + PLC 控制（西门子），主传动进口控制系统、变频无级调速，精度高、稳定性好、自动化程度高。
- 加热室顶部铺设磁化高铝板，保证无杂质掉落造成麻点、疵点。
- 加热采用螺旋矩阵式结构、分区域控温；温度测量用分布式远程热电偶测温模块（I-7018），抗干扰强、精度高；炉丝通断用固态继电器控制，稳定可靠无噪声。
- 全封闭加热炉体保温良好：25 ℃→700 ℃ 升温约 3~4 h；24 h 自然降温平均每小时低于 15 ℃，生产能耗低。
- 炉体分上下两部分、上部可升降便于检修；加热段传动辊道用优质陶瓷辊，表面光洁度好、寿命长。
- 软件功能：控温模块调节算法；自动升温三相均衡用电、非加热过程自动消除相不平衡；热电偶工作自动监控并报警提示故障位置；每根炉丝可单独设温度与功率实现微调；完善的操作提示（对话框式）；误操作防范（限制数据取值范围）；自动存储报警记录；分级权限管理；自动监控几乎全部传感器与执行元件；自动储存、更新玻璃加工工艺参数。
- 警示标识齐全（请注意高度、小心碰撞、当心夹手）。

### 6.3 成型压制段（压机）功能描述

- **定位与重要性**：整条线最关键部分，玻璃成品合格与否关键在压机功能完整性、调整手段完善性与功能配套性；汽车玻璃光学要求严格，各零部件加工精度比建筑玻璃设备高几个等级。
- **典型供货范围案例**（4 mm 后档全钢化、2.1 mm 应力达 28 MPa 的需求）：压机两套、风栅一套、卸片一套、315 kW 风机 4 台、轴流风机 2 台、模具装卸架 2 套、风栅装卸车一套，总功率 1800 kW。
- **可加工规格**：可加工厚度 1.6~5 mm（2.1 mm 级汽车玻璃）；最大玻璃 2300 mm × 1600 mm，最大拱高 180 mm；最小玻璃 500 mm × 800 mm；辊道 Ø70 mm。
- **工艺流程**：玻璃由炉体通过辊道传送进入保温压制段 → 精确定位机构将玻璃定位在凹模上 → 与上凸模压合完成压制，使玻璃边部与型面呈现设计状态。
- **关键机构**：
  - 压机段腔体内有加热功能，使玻璃成型过程中呈现最佳状态；压机段互换性要求严格，保证模具在不同压机生产的玻璃状态一致；上下模具姿态可微调；模具温度控制：阳模加热使用耐高温底板防高温变形；梭车加热线使用坦克链连接。
  - 压机两套"一备一用"，主要目的是减少换模时间：换模时间由单模压机的 12 小时缩减到 5 小时以内（流程：脱离炉体 → 到换模位置降温 → 换模、排辊道 → 升温 → 保温；与熟练程度和玻璃形状有关）。
  - 传动：所有压机传动均为国产伺服电机传动；齿形链条将伺服电机动力传到传动轴，经久耐用噪音小；传动分上下两部分，上部接触玻璃部分用耐高温芳纶绳套包裹钢棍，在模具内传动玻璃；下部为传动轴，经链轮将动力给上部传动辊道；梭车驱动亦由伺服电机控制位置；压机行走使用气囊结构。
  - 压机段只有卸片传送辊道为变频传送。
- **冷却与后续**：做夹层玻璃时使用专用风栅方式冷却；卸片段是将玻璃与风栅脱离的装置，脱离后玻璃由卸片段传送到冷却段，再经冷却、检测、清洗、合片等工序。
- **产量**：普通白玻最快 16 秒/片；镀膜玻璃最小 22 秒/片。
- **技术亮点**：可钢化离线镀膜、在线镀膜玻璃；可大小片同时加工，**双银 LOW-E 玻璃与白玻同时生产**是该炉最大亮点；具备定位功能、纠偏功能。

## 七、光伏玻璃工艺技术（设备技术规格要点）

光伏章节为典型的设备招标技术规格（综合线：钢化炉/磨边/清洗/丝印/镀膜/打孔/机械手），核心验收指标如下。**通用条款**：设备通讯 Profinet（含工作状态、速度、是否允许进/出片信号）；单体设备不设密码、预留通讯接口；电气元件与机械配件采用国际知名品牌（PLC 首选西门子，低压电器与变频器施耐德，轴承 SKF/NSK，传动电机 SEW，其它电机 ABB，仅供参考）；设备到货由厂家包卸货、保管、安装；设备外表颜色业主定。

### 7.1 钢化炉

**案例一（48 m / 60 m 综合线钢化炉）**
- 加工规格：48 m 炉最大 2500 mm × 1300 mm、60 m 炉最大 2500 mm × 1130 mm，最小均 1650 mm × 985 mm；板厚 1.5~4 mm（≤ 2 mm 需可半钢处理，< 2 mm 不作考核；2.5 mm 要求能全钢但不作考核）。
- 产能验收：48 m 炉按 2272 mm × 1128 mm × 2.0 mm（半钢）≥ 12 片/min；60 m 炉同规格 ≥ 15 片/min；钢化成品率 ≥ 99.5%。
- 能耗：≤ 1.6 kWh/m²（2 mm 半钢）；急冷段高压风机采用膜片式联轴器直连（不采用皮带）；风栅段做降噪处理；炉宽按最大板宽考虑（60 m 炉 1130 mm、48 m 炉 1300 mm）；具倒片功能（生产过程中可从上片台处落片，辊道下方设碎玻璃托盘）；炉内压缩空气用气量按标态（0 ℃、101.325 kPa）提供；样片处理 300 mm × 300 mm。

**案例二（产能与质量验收）**
- 玻璃品种：太阳能光伏压延玻璃、浮法玻璃；最大 2500 mm × 1128 mm（2.0 全钢），最小 450 mm × 300 mm。
- 厚度规格：2.0 全钢——浮法 2.0~2.10 mm、压花 2.0~2.15 mm；2.0 半钢——浮法 2.0±0.1 mm、压花 2.0±0.15 mm。
- 运行方式与产能：24 h 连续运行；2.0 mm 全钢 ≥ 30000 m²/天，2.0 mm 半钢 ≥ 37000 m²/天。
- 能耗：2.0 mm 全钢 ≤ 3.4 kWh/m²；2.0 mm 半钢 ≤ 1.35 kWh/m²。工作环境温度 -10~60 ℃。
- **质量指标**：
  - 弓形弯曲 ≤ 0.20%；整板波形（300 mm）≤ 0.30 mm；边部翘曲 ≤ 0.35 mm；边部变形 ≤ 0.30 mm；
  - 表面应力：2.0 mm 全钢化 ≥ 110 MPa；2.0 mm 半钢化 ≥ 70 MPa；同一片玻璃应力极差 ≤ 10 MPa；
  - 弯曲强度：前板玻璃 ≥ 140 MPa；背板玻璃 ≥ 130 MPa；
  - 颗粒度：2.0 mm 全钢（距冲击点 80 mm 以外任意 50 mm × 50 mm 区域）≥ 40 粒；2.0 mm 半钢按 GB/T 17841—2008 要求；
  - 落球冲击：2.0 mm 全钢——1040 g±10 g 钢球（Ø63.5 mm）自 1000 mm 高度自由落下不破坏；2.0 mm 半钢——227 g±10 g 钢球（Ø38.1 mm）自 1000 mm 高度落下不破坏；
  - 外观：表面无钢化炉造成的脏污、划伤；下表面无板下白雾；无风斑印；无明显波浪辊印；每批钢化质量一致；良品率 99.8% 以上。
- 引用标准：GB 11614—2009《平板玻璃》、GB/T 30984.1—2015《太阳能用玻璃》、GB/T 34328—2017《轻质物理强化玻璃》、JC/T 2454—2018《超薄钢化玻璃》及光伏行业国内外标准。

### 7.2 磨边机组

- 加工规格：最大 2500 mm × 1300 mm、最小 1650 mm × 985 mm，板厚 1.5~4 mm；磨边成品率 ≥ 99.5%。
- 质量要求：对角线偏差 ≤ 0.5‰；边部直线度 ≤ 0.1 mm/m；倒角 0.5~3 mm、45°±2°（四角偏差 ≤ 0.5）；"C"型边要求深度 0.5~2 mm、弧度均匀、上下对称、无划痕崩边。
- 配置要求：3 组磨头，磨头跳动 < 0.02 mm、转速 ≥ 3600 r/min，可单独启停；磨轮冷却水嘴为 Ø14 mm 紫铜管（壁厚 0.8 mm），每磨头左右各一、可调；集中供水（取消水箱与水泵，保留接水盘）；倒角机双伺服驱动；挡爪通轴设计、高精度气缸控制；输送胶辊包丁腈橡胶、黑色、邵氏硬度 65~70；机组中间加两道支撑防薄玻璃变形；每条线具备一键停止/暂停、单台磨边机 ≥ 4 个急停开关（两边各 2 个以上）；转片台 2 个急停；与水接触部件（转向台轴承等）用不锈钢并防水；同步带、轴轮不得划伤板面；磨边后镀膜前一体清洗机、磨边后清洗机、丝印清洗机均用循环水 2（pH 6~9，SS ≤ 10 mg/L）。

### 7.3 清洗机组

- 加工规格同磨边机（最大 2500 × 1300 / 最小 1650 × 985，板厚 1.5~4 mm）；清洗成品率 ≥ 99.5%。
- 配置：集中供水（不设水箱）、集中供风（不设风机，风加热保留）；各清洗机配高压喷淋、预清洗，具压力显示与水量流量显示；丝印前清洗机、磨边镀膜二合一清洗机、包装前清洗机设**除静电装置**；轴承及与水接触件防水处理。
- 质量要求：清洗后表面洁净、干燥、无静电，检验灯箱下表面与边角无可见杂物、水渍，无胶印、风刀印；磨边镀膜清洗后、丝印清洗后板面需达**电子级原片表面质量**；包装清洗后表面须烘干、不允许挂水。

### 7.4 丝网印刷机组

- 加工规格同上；丝印成品率 ≥ 99.5%；节拍满足 ≥ 6 PCS/min 级生产线配套。
- 印刷要求：刮刀方向为短边刮；回油刀恒压、快速回油、可自动加油；机头保证水平，印刷速度 600 mm/s 条件下不得抖动；工作台面整体水平精度 0.1 mm，传输不划伤玻璃；印刷与梭子传动两端均设电气限位 + 机械限位双重保护；玻璃板尺寸调整时 CCD 定位半小时内完成；采用丝杆升降机构（不考虑链条）。
- 烘干/固化炉：一次烘干炉温度常温~300 ℃ 任意设定（±3 ℃ 可调），二次烘干炉常温~200 ℃（±3 ℃），炉膛前后及两侧温差 ≤ ±5 ℃，炉盖温度分布温差 ±2.5 ℃ 可调、数字显示控制；烘干炉电器元器件及电机**防爆**、配防爆排风机；四柱式升降便于维修；设排废口（定时或人工开闭）与排湿装置。

### 7.5 镀膜机、预热炉、烘干炉

- 镀膜成品率 ≥ 99.5%；机器人与关键部件国际知名品牌。
- 预热机：温度常温~200 ℃ 任意设定（±3 ℃ 可调），炉膛前后及两侧温差 ≤ ±5 ℃。
- 固化炉：温度常温~300 ℃ 任意设定（±3 ℃），烘干炉内热循环风机每节炉体独立控制。
- 均需考虑防爆与防腐蚀处理。

### 7.6 激光打孔机组

- 加工规格同上；打孔成品率 ≥ 99.5%；加工节拍 ≥ 6 PCS/min（以 2.0 mm 板厚打 Ø12 mm 孔为考核）。
- 质量要求：不允许孔不通、孔裂纹、孔崩边、偏孔、斜孔、切割瘤；最小孔距 ≤ 200 mm，配置收孔收尘装置；直径偏差 0.1 mm；位置偏差 ±0.3 mm；孔周崩边 a/b/c/d ≤ 0.2 mm，每孔不超过一处。
- 配置要求：单台打孔机组激光器 3 头配置（激光器按国产选型）；离网范围行程 10~50 mm 任意调节并能快速复位；压延玻璃打孔时自动加打孔助剂（用纯净水）；孔距范围内可在 X/Y 轴任意坐标进行多孔或单孔作业；可在操作屏内设计打孔坐标系且与实际打孔位置对应。

### 7.7 上、下片机械手

- 加工规格同上；机器人品牌采用国际知名品牌；抓放玻璃板过程中不得有吸盘印，玻璃传输、定位过程中不得出现擦伤等；下片装置需考虑废片工位。

## 八、电子玻璃标准：GB/T 34328—2017《轻质物理强化玻璃》要点

（2017-10-14 发布，2018-09-01 实施）

- **适用范围**：厚度 ≥ 1.3 mm 且 < 3 mm 的轻质物理强化玻璃（< 1.3 mm 可参照使用）；**不适用于化学强化玻璃**。
- **定义**：厚度小于 3 mm、经热处理工艺之后力学性能得到提高的钠钙硅玻璃。
- **分类**：按原片种类分平板/压花；按碎片状态分 A 类（对碎片状态有要求）/ B 类（无要求）；按应用领域分光伏用、建筑用、家电家居用。
- **厚度偏差及厚薄差**（1.3 ≤ d < 3 mm）：最大允许厚度偏差——平板 ±0.10 mm、压花 ±0.20 mm；最大允许厚薄差 0.10 mm。
- **边长偏差与对角线差**：按应用领域及边长/对角线分段规定（光伏用较严，如 > 2000 mm 边长允许 -2.5 mm 等），详见标准表 2、表 3。
- **孔的要求**：圆孔孔径允许偏差（公称孔径 < 100 mm 时约 ±0.3 mm 级别，≥ 100 mm 由供需双方商定）；孔边部加工质量、其它孔与开口由供需双方商定。
- **外观质量**：
  - 平板玻璃：线条、线道、裂纹及缺角不准许；划伤、点状缺陷按板面积 S 乘系数限量（如划伤 1.0×S 个），100 mm 直径圆面积内划伤 ≤ 2 个、≥0.3 mm 点状缺陷 ≤ 3 个；爆边每米边长不多于 1 处（长度 ≤ 5 mm、向板面延伸 ≤ 1 mm、向厚度延伸 ≤ 厚度 1/2）；光学变形透明玻璃 ≥ 40°（2 mm 以下）/ ≥ 45°（2~3 mm）级别；
  - 压花玻璃：压痕、皱纹、线条线道裂纹、霉变、不可擦除污物、开口气泡、膜层脱落均不准许；圆形/长形气泡、划伤、夹杂物按面积限量，不允许黑色夹杂物。
- **平整度**：弓形弯曲度 ≤ 0.2%；波形弯曲度 ≤ 0.3 mm；边部翘曲 ≤ 0.5 mm；边部变形 ≤ 0.3 mm。
- **弯曲强度**：平板——非釉面（镀膜或非镀膜）≥ 120 MPa、釉面 ≥ 75 MPa；压花（镀膜或非镀膜）≥ 90 MPa。
- **抗冲击性**：试验后试样不破坏（釉面玻璃是否试验由供需双方商定）。
- **碎片状态**：A 类——任意 50 mm × 50 mm 区域内最少碎片 ≥ 15 片，允许少量长条形碎片（长度 ≤ 100 mm）；B 类无要求。
- **表面应力**：A 类平板 ≥ 95 MPa；B 类平板 > 60 MPa；压花玻璃不测表面应力；同一片玻璃应力极差 ≤ 20 MPa。
- **耐热冲击性能**：应耐 200 ℃ 温差不破坏。
- **霰弹袋冲击性能**：建筑用、光伏用 A 类需测试；家电家居用 A 类及 B 类不测。合格判据（满足其一）：霰弹袋下落高度 1200 mm 试样不破坏；或保留在框内的无贯穿裂纹碎片长度 ≤ 200 mm。
- **光伏透射比**：应用于光伏盖板领域时，非镀膜轻质物理强化玻璃 ≥ 91.5%（镀膜玻璃另按标准）。
- **检验规则**：检验分出厂检验与型式检验；检验项目含尺寸偏差、外观质量、平整度、弯曲强度、抗冲击性、碎片状态、表面应力、耐热冲击性能、霰弹袋冲击性能、光伏透射比（按应用领域取舍）；组批按同一厚度、同一规格连续生产 1200 块为一批；外观/尺寸/平整度随机抽样（批量 26~90 块抽样 13 块级别）；光伏透射比从合格制品中抽 1 块或同工艺试样 5 块检验；各单项合格方判定该批合格。有下列情况之一应进行型式检验：新产品或转厂生产的试制定型鉴定；结构、材料、工艺有较大改变可能影响性能；停产 1 年后恢复生产；出厂检验结果与上次型式检验差异较大。

## 九、结语与寄语

**好玻璃 → 好钢化玻璃**
- 颗粒均匀
- 冲击强度好
- 平整度好（弓形、波形达标）

> 优质钢化玻璃既取决于优质设备性能，更取决于正确的操作方法与良好的操作经验——关键在于保证优良的光学性能与较高的成品率，操作工要不断在两者之间寻找最佳平衡点。
