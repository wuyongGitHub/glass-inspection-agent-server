# 常见缺陷补充词典（条纹/白斑/翘曲/发霉/自爆等）

> 说明：本文补充种子知识库未详写的缺陷条目。种子文档已覆盖：气泡、结石、杂质、划伤、崩边、
> 倒角不良、麻点、字符缺失/缺印/漏墨/油墨不良；应力类见《应力斑与退火应力》。
> 每类缺陷请按"定义→成因→影响→检测"理解，具体判级阈值以部门现行标准/客户规格书为准。

## 条纹 / 波筋 / 波浪纹（Striae / Wave）

定义：玻璃体内呈线条状、带状或波浪状的折射率差异区域，透光观察时似水波纹、透过玻璃看物象变形。
成因：玻璃液均化不良（成分不均）、熔窑料道温度不均、锡槽对流/冷却不均、退火不均放大折射差异。
与应力斑区分：条纹源于成分不均造成的折射率差异（静态变形），应力斑源于应力双折射（偏光下呈彩色条纹），两者机制不同、常同时存在。
检测：暗室用投影光栅/斑马法观察波筋；高要求产品用光畸变仪定量。
影响：建筑玻璃看物象变形引起投诉；电子/车载玻璃直接影响成像质量。

## 白斑与黑点（White Spot / Black Dot）

定义：表面或内部的点状缺陷，直径通常零点几毫米到几毫米。
- 白斑：半透明白色点，常见成因：析晶（玻璃本身晶体析出）、表面碱析风化（潮湿存储）、
  胶带/贴纸残胶白印（加工环节）。
- 黑点：不透明黑色颗粒，常见成因：耐火材料/砖屑掉入玻璃液、金属颗粒（铁锈/设备磨损屑）、
  未燃尽碳粒、丝印油墨颗粒。
检测：同轴光明场或透射背光配合高分辨率相机；先判断在表面还是内部（对焦变化确认）。
注意：黑点常与"杂质/结石"重叠，按客户缺陷分类表命名，避免跨厂口径不一。

## 金属与耐火材料夹杂（Metal / Refractory Inclusion）

定义：玻璃中混入的金属碎屑或耐火材料颗粒，多呈带金属光泽或不规则深色颗粒。
成因：熔窑/锡槽耐火材料剥落侵蚀、设备（辊道、吊夹）金属磨损屑落入、碎玻璃中夹带金属。
影响：金属颗粒热膨胀与玻璃差异大，周边易产生应力裂纹，钢化时可能成为自爆源。
检测：磁性金属可先过磁选排查来料；成品用透射背光+面阵相机，缺陷可加金相确认材质。

## 翘曲与弯曲（Warpage / Bending）

定义：玻璃板面不平、局部弓起或整体弯曲，与平整度/弯曲度指标相关。
成因：退火冷却不均（上下表面温差）、钢化风栅冷却不均、夹层合片压力不均、超薄玻璃搬运变形。
检测：平整度用塞尺/激光轮廓仪；钢化弯曲度按标准（弓形/波形）用专用量具测量。
影响：弯曲过大的玻璃无法正确贴合/安装，钢化炉内还易炸片。

## 炸口 / 裂口 / 裂纹（Crack / Chip Line）

定义：玻璃边缘或板面的开裂破损。常见场景：切割后边部微裂纹在搬运中扩展、
钢化过程中因边缘缺陷或应力集中炸裂、钻孔/磨边应力集中处开裂。
成因：切割刀压过深/过浅、边缘缺陷未去除、应力斑区域、受外力冲击、热冲击。
检测：裂纹在特定光照下呈亮线，暗场/侧光最明显；裂纹走向可辅助判断受力方向。
注意：端面有微裂纹的玻璃强度大幅下降，判定时结合崩边、裂口一起评估。

## 辊道印 / 压痕 / 炉辊痕（Roll Mark）

定义：与输送方向垂直或平行的条状、辊距周期性痕迹，多见于退火窑辊道或钢化炉辊，压延玻璃则为辊面印迹。
成因：辊道表面脏污/粘附玻璃屑/辊径磨损不均、钢化炉辊温度不均、压延辊损伤。
检测：低角度暗场可突出表面辊痕；周期性条纹建议按辊周长换算排查对应辊位。
影响：表面辊痕影响外观与后续镀膜/印刷附着力。

## 光学变形 / 光畸变（Optical Distortion）

定义：透过玻璃观察物体发生畸变、重影或晃动，本质是厚度不均、表面不平或折射率不均对光路的影响。
成因：浮法玻璃厚度波动/波筋、钢化加热不均导致表面凹凸、夹层胶片厚度不均、退火带残余应力。
检测：斑马法（观察条纹）为通用初筛；汽车前挡用光畸变仪（按反射投影栅格定量）。
判定：与观察角度、玻璃位置有关，按标准规定视区取样判定。

## 玻璃发霉（风化 / 雾化）

定义：玻璃长期处于潮湿环境，表面碱金属离子析出与空气中水汽、CO2 反应生成白斑/白雾/彩虹膜，
严重时表面失透。
成因：仓储潮湿、包装防潮不良（无防霉纸/干燥剂失效）、长期堆放通风差。
预防：干燥通风存放、防霉纸隔离、避免玻璃间水膜长时间接触；轻度霉斑可清洗/抛光处理。
检测：外观白雾/白斑、透光率下降；需与"碱析（出厂即有的表面析出）"区分。

## 钢化玻璃自爆（Spontaneous Breakage / NiS）

定义：钢化玻璃在无外力作用下自行破碎，典型特征是"蝴蝶斑"状裂纹起点（两片蝴蝶形碎片）。
成因：玻璃中硫化镍（NiS）等杂质在钢化急冷时被冻结为不稳定相，使用中相变膨胀引起裂纹；
其次为结石/金属夹杂周边应力集中。
概率：行业内经验统计自爆率较低（约千分之几量级），并非所有钢化玻璃都会自爆。
对策：原料控制降低 NiS 引入；重要幕墙/天窗用均质处理（HST，将玻璃加热到约 290℃ 使
有问题的玻璃提前自爆剔除），可显著降低使用期自爆率。
检测：无法用外观筛查完全杜绝，靠工艺控制+均质；破碎后蝴蝶斑可辅助确认自爆而非外力。

## 缺陷快速判断口诀

- 泡→气、点→料、线→擦碰、边缺→切磨搬、花斑→应力/冷却、雾白→潮/风化。
- 不确定先判断"表面还是内部、规则还是不规则、颜色、是否随焦平面变化"，再对分类表。
