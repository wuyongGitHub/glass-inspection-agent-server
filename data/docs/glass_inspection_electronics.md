# 电子玻璃检测指标详解

> 适用对象：手机/平板/笔电触控盖板（Cover Glass）、车载显示盖板、触控 Sensor 基板、
> TFT 显示基板、智能眼镜镜片等。电子玻璃以超薄（0.3~1.1mm）、高强度、高洁净为特点，
> 通常在百级/千级洁净环境生产与检测。
> 数值标注说明：电子玻璃几乎全部指标由"客户规格书+双方限度样板（Limit Sample）"约定，
> 本文件数值均为行业常见参考口径（示例性质），实际以规格书为准；规格书缺失时宁可明说
> "需查规格书"，不要自行估算判级。

## 检测项目总览

外观微观缺陷分级 → 尺寸与孔位 → 平整度/波纹度/粗糙度 → 强化应力（化学强化/物理强化）
→ 光学（透过/反射/雾度/彩虹纹）→ 硬度与机械强度 → 洁净度 → 信赖性 → 丝印装饰。

## 一、外观微观缺陷分级（电子玻璃核心难点）

分级三要素：分区（主视区 A/次视区 B/非视区 C 或按功能分区）＋ 缺陷类型（点/线/面）＋ 尺寸数量。
- 点缺陷：长宽比小于 3:1（如颗粒、尘埃、针孔、凹点、白点、气泡结石）。
- 线缺陷：长宽比大于等于 3:1（划伤、擦痕、刀痕）。
- 分区示例逻辑：显示屏可视区域为 A 区，最严；丝印区/电极区为 B 区；裁切边缘为 C 区。
- 常见尺寸档位参考：直径 0.05~0.1mm、0.1~0.15mm、0.15~0.3mm、>0.3mm 分档，逐档给允许数量；
  A 区 0.1mm 级缺陷通常要求"近乎 0 允收"（示例：>0.1mm 点缺陷 NG，0.05~0.1mm 限量 1~2 点）。
- 线缺陷口径示例：A 区宽度 <0.05mm 且长度 <1mm 限量；可视深划伤零容忍。
- 关键：电子玻璃判级以"极限样板+文字规格"双确认，极限样板会签后作为仲裁依据。

## 二、尺寸与孔位

- 长宽公差：盖板 CNC 加工后常见 ±0.05~0.1mm（参考）；弧边/开槽件加严。
- 厚度：0.3~1.1mm 常用；同一片厚度均匀性（TTV）对贴合与显示影响大。
- 孔位（听筒孔、按键孔、摄像头孔）：孔位置公差常见 ±0.05mm 量级，孔壁需光滑无崩口，
  崩口会造成强化后强度下降。
- 外形：异形轮廓（水滴屏、打孔、2.5D/3D 弧面）用检具/CCD 轮廓仪比对，关键尺寸按图纸 CPK 管理。
- 检测：CCD 影像测量仪、三坐标、高度规（测弧边）。

## 三、平整度/波纹度/粗糙度

- 翘曲（Warp）：整片玻璃弯曲程度，以对角弦高或翘曲率衡量。参考口径：全尺寸翘曲率约
  ≤0.1%~0.15%（示例，超薄件可能要求绝对值 <0.3mm 量级），翘曲过大会导致贴合偏移与边缘彩虹。
- 波纹度（Waviness）：局部周期性起伏，以 P-V（峰谷值，μm 级）表征，波纹过大会造成贴合后
  光学干涉（彩虹/云斑）。
- 粗糙度（Ra）：磨边/抛光面以 Ra 表征，CNC 磨边常见亚微米级以下要求；镜面抛光更高。
- 蚀刻台阶/边缘倒角精度影响强化均匀与外观。
- 检测：激光干涉/激光轮廓仪、白光干涉仪、Warp 仪、接触式台阶仪。

## 四、强化应力（化学强化为主）

- 化学强化（离子交换）：将玻璃浸入高温熔盐（硝酸钾等），表面 Na+/K+ 离子交换形成表面压应力
  与强化层。常用指标：表面压应力 CS（Compressive Stress）与强化深度 DOL（Depth of Layer）。
  参考常见规格区间：CS 约 650~900MPa，DOL 约 30~60μm（示例值，视厚度与玻璃牌号调整；
  也有高强度规格 CS 更高或 DOL 更深的工艺）。
- 中心张力 CT：由 CS/DOL/厚度换算得出；CT 过高玻璃易碎裂或自爆风险升高，按规格上限控制。
- 物理钢化：车载曲面/3D 件可能采用物理钢化，判定同钢化玻璃（碎片试验、应力均匀性）。
- 应力均匀性：逐片或抽检 CS/DOL，SPC 监控熔盐寿命与工艺漂移。
- 测试方法：表面应力仪（折射法）测 CS/DOL，边部应力另法；碎片形态辅助验证强化效果。
- 强化后强度验证：四点弯曲、落球、跌落类抽检（见力学节）。

## 五、光学性能

- 可见光透射率：盖板（含或不含 AR/AG/AF 膜）规格常见 ≥90%~92% 量级；透过率不足多因镀膜
  反射或玻璃本体吸收。
- 反射率：含 AR 增透膜时反射率明显下降（常见目标反射率 1% 以下量级，视规格）。
- 雾度 Haze：参考常见规格 <0.3%~0.5%；雾度过大影响通透清晰。
- 色度均匀性：白画面下无色斑、无整体偏色；镀膜件测 Lab/色坐标均匀性。
- 彩虹纹/牛顿环：强化、蚀刻或贴合后干涉条纹，属电子玻璃常见客诉；需从工艺端排查
  （应力不均、贴合胶厚不均、表面微结构）。
- 光畸变：曲面/弧边盖板在弧面区域看物象是否变形，影响大尺寸显示件体验。
- 工具：分光光度计/雾度仪、色差仪、成像式测量（画面均匀性）。

## 六、硬度与机械强度

- 表面硬度：玻璃基材莫氏约 6~7 级；盖板规格常以"表面压痕/跌落"行为间接约定。
- 弯曲强度：四点弯曲法测断裂强度，强化后强度可达基材数倍（规格常用应力值或载荷表达）。
- 抗跌落/冲击：按产品定义高度与着落面抽检，破碎后要求碎片细小钝化（化学强化玻璃破裂后
  呈细小颗粒，边缘较钝）与基板不外露。
- 边部强度弱点是电子玻璃薄弱环节，崩边/微裂纹直接降低强度——外观检测对边部从严的意义在此。

## 七、洁净度与表面状态

- 微粒/异物控制：表面允许颗粒按尺寸档位计数（与 A 区外观同源），超出按脏污判退。
- 可清洁性/油污：清洗后无水渍指纹、无清洗剂残留。
- 保护膜：出货贴保护膜，检查贴膜无气泡、无翘边、撕膜无残胶（影响客户端首检）。

## 八、信赖性试验（周期抽检）

- 高温高湿：典型 85℃/85%RH 长期放置，考核强化应力衰减与膜层/贴合耐久。
- 冷热冲击/温度循环：加速模拟环境温度变化，不允许开裂、膜层剥离。
- 盐雾/化学品耐受：模拟汗液、清洁剂侵蚀。
- 压力锅/高压加速老化：用于快速评估可靠性差异。
- 试验后复测：外观、透过率、雾度、应力（CS/DOL 衰减）、附着力是否达标。

## 九、丝印/装饰与功能膜

- 丝印（盖板背面按键/logo/遮蔽）：色差 ΔE、附着百格、油墨硬度与耐溶剂；
  遮蔽油墨以 OD 值保证不透光，红外/摄像头开孔区按透光规格（透红外墨水）。
- AF（防指纹）膜：水滴角（参考 ≥105°~110° 量级）、耐磨擦后水滴角保持率；
- AR（减反）膜：反射率、色坐标、耐摩擦；AG（防眩）膜：雾度/粗糙度、防眩等级。
- 膜层异常：膜点、针孔、彩虹、附着不良、异色。

## 十、检验流程与抽样（电子厂口径）

- 全检外观：AOI（高分辨率+多光源）初检 + 人工复判（显微镜/放大镜复核极限边界缺陷）；
  尺寸应力光学等仪器抽检。
- 洁净环境作业，缺陷判定按"文字规格+极限样板+双方会签"三件套，避免口径纠纷。
- 抽样：破坏性试验按批次，外观按 AQL 或全检，关键批次要求全尺寸记录。
- 每片可追溯：唯一 ID/镭射码绑定检测图像与数据，客户投诉时按码反查工序。

## 十一、常见客诉与原因映射

- 划伤/颗粒 → 清洗、搬运、环境洁净度；彩虹纹 → 强化/贴合应力不均；
- 强化不足开裂 → CS/DOL 漂移、熔盐失效；崩边 → CNC/倒角/搬运；
- 透过率低/偏色 → 镀膜与玻璃本体；贴合气泡白点 → 后续制程（本厂管到玻璃时注意边界）。
