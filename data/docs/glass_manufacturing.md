# 平板玻璃生产工艺流程

> 说明：了解各工序做什么、会带来什么缺陷，有助于把产线缺陷追溯到工序。

## 全流程概览

配料 → 熔化 → 成型 → 退火 → 切裁 → 磨边/倒角 → 清洗 → 深加工（钢化/夹层/镀膜/丝印）→ 检验包装

## 工序详述

### 1. 配料
按配方称量石英砂、纯碱（碳酸钠）、石灰石、白云石、芒硝/澄清剂及碎玻璃（熟料）并混合均匀。
质量控制：称量精度与均匀性直接影响成分稳定；碎玻璃需除铁除杂，混入异物会变成结石、杂质缺陷。

### 2. 熔化
配合料在熔窑约 1400~1600℃ 熔化为玻璃液。澄清剂（如芒硝）在高温分解产生气体上浮，把气泡带出玻璃液。
温度曲线波动、澄清不足、还原性气氛控制不当，是内部气泡、小气泡（灰泡）的根源。

### 3. 成型
- 浮法：玻璃液流入锡槽，漂浮在 900℃ 以上锡液表面，自然摊平抛光，经拉边机控制宽度厚度后缓慢进入退火窑。
  锡槽带来的典型问题：沾锡/锡灰（下表面麻点、白雾）、锡石颗粒、光畸变（锡液对流/温度不均）。
- 压延：玻璃液直接通过压延辊间隙压出板带，辊面花纹决定压花玻璃纹理；辊面损伤/粘附会造成压痕、花纹不均。

### 4. 退火
板带在退火窑内按设定温度曲线缓慢冷却，使残余应力降到允许范围（见《应力斑与退火应力》篇）。
退火曲线不良的后果：应力斑、翘曲、切割困难（应力大易炸）。

### 5. 切裁（切割）
按订单尺寸用金刚石/硬质合金刀轮划痕再掰断。刀轮磨损、压力不当、切割速度不当会造成切割线波浪、
掰断崩边崩角、裂口；切割后边缘存在微裂纹，是后续搬运碰伤和强度下降的来源。

### 6. 磨边/倒角
用磨边机将玻璃边缘磨平并倒角（C 角/R 角），去除微裂纹。砂轮磨损超周期、进给量漂移、定位偏移
会造成倒角不良、磨边崩边、边部划伤，磨边粉残留需靠后续清洗去除。

### 7. 清洗
高压水/毛刷清洗去除粉尘、油污、磨边粉。毛刷夹砂、水洗后烘干不彻底会带来二次划伤或水渍。

### 8. 深加工（按产品）
- 物理钢化：加热至接近软化温度后风栅急速均匀冷却，形成表面压应力。风压不均/风嘴堵塞 → 风斑、
  应力不均、碎片颗粒不均，详见《应力斑与退火应力》与自爆相关条目。
- 夹层：两片玻璃夹胶片经高压釜合片；合片温度压力异常会造成胶片气泡、脱胶、边缘欠透明。
- 镀膜：磁控溅射/在线镀膜，膜层均匀性与污染控制关键，异常表现为色差、膜点、附着不良。
- 丝印/彩釉：油墨印刷后烘干；常见缺陷为字符缺失、缺印、漏墨、油墨不良（详见种子知识库字符类缺陷）。

### 9. 检验包装
AOI+人工灯检复判，缺陷定位与截图上传系统；包装前防霉纸/干燥剂使用不当或仓储潮湿会导致玻璃发霉雾化。

## 缺陷到工序的快速映射（排查方向）

- 气泡/灰泡 → 熔制澄清；结石/杂质 → 原料与耐火材料、碎玻璃污染；
- 划伤 → 辊道、堆叠摩擦、清洗毛刷；崩边 → 切裁与搬运；
- 麻点/白雾 → 锡槽（浮法）或辊道/炉辊；应力斑/翘曲 → 退火与钢化；
- 丝印字符问题 → 丝印工序；色差/膜点 → 镀膜工序。
